# Psicóloga Angélica De Gennaro — Red WordPress Multisite

Repositorio del sitio y tema personalizado para la red **WordPress Multisite** de la **Psicóloga Angélica De Gennaro** (`https://healthcare.eurekraftve.com/`).

## Estructura del Multisite (Subdirectorios)
- **Sitio 1 (Portal Principal):** `https://healthcare.eurekraftve.com/`
- **Sitio 2 (Barquisimeto, Edo. Lara):** `https://healthcare.eurekraftve.com/barquisimeto/`
- **Sitio 3 (Cabudare, Edo. Lara):** `https://healthcare.eurekraftve.com/cabudare/`
- **Sitio 4 (Valencia, Edo. Carabobo):** `https://healthcare.eurekraftve.com/valencia/`

## Estructura del Repositorio
- `backups/v1-multisite-gutenberg-snapshot.json`: Respaldo completo del estado base (`v1.0-multisite-base`) de las 4 sedes en Gutenberg + Simply Schedule Appointments antes de crear el tema personalizado.
- `themes/angelica-multisite/`: Tema personalizado compartido por todas las sucursales de la red.
